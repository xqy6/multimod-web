MODULO 离线版使用说明

1. 把整个 offline-package 文件夹复制到 U 盘。
2. 到学校机房后插入 U 盘，双击 start-offline.bat。
3. 会弹出 MODULO Offline Server 服务窗口，浏览器随后自动打开
   http://127.0.0.1:4100，无需联网。
4. 服务窗口要保持打开，关掉它网站就停止。
5. 想给同一局域网的其他电脑用，双击 start-lan.bat，
   然后让其他电脑访问终端里显示的 http://局域网IP:4100。

离线版已内置账号、聊天记录和网盘数据。
